GitHub Pages向けオンライン号車案内 修正メモ

症状1:
GitHub Pages上で「オンライン号車案内」が読み込み中のまま表示されないことがある。

対策:
- Jina Reader + AllOrigins の2取得経路を並行利用。
- 対象ページ候補を最大5まで削減。
- タイムアウトと再取得ボタンを追加。

症状2:
上野駅などで「5号車付近」の下に「1号車」と表示される。

原因:
掲載元の「5号車（1号車）：階段・エスカレーター」の括弧内は、10両編成時や別ホーム到着時の代替号車を意味するが、旧解析が括弧内を設備説明として扱っていた。

対策:
- 括弧外 = 基本の号車
- 括弧内 = 別条件の号車
- コロン以降 = 階段・エレベーター等の設備
として分離。
- 「（ ）内は10両編成時…」等の注記も保持し、例:「10両編成時：1号車付近」と表示。
- 旧誤解析キャッシュは自動破棄。

注意:
第三者の公開取得サービスや掲載元が停止・制限された場合、オンライン部分だけは失敗する可能性があります。静的内蔵データは影響を受けません。
