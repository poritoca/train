GitHub Pages 配布メモ v46
========================
配布ZIPの全24ファイルを、GitHub Pagesの公開ディレクトリへ配置してください。
既存ファイルは同名上書き、新規の iphone-alerts.html も一緒に配置します。
ZIPそのものを置くだけでは展開されません。

同時に更新するコード・画面ファイル
- index.html
- journey-ui.js
- journey.css
- sw.js
- iphone-alerts.html（新規）

公開後は画面の「バージョン 46」を確認してください。
降車位置の検索欄は「降車位置」タブの中に移動しています。
旧版が残る場合は見守りを終えてから再読み込みしてください。キャッシュは46.0です。
ブラウザのサイトデータを消すと保存プリセットも失われるため、先に書き出して保存できます。
Brrrowser等の別ブラウザへは、プリセットのJSON書き出し／読み込みで移行します。

保存済みの往路／復路、乗換、10区切り表示、駅データは引き継ぎます。
標準ショートカットの通知設定は利用者がiPhone側で行います。Web公開だけでは設定されません。
このZIPの作成時点で、こちらからGitHubへの公開操作は行っていません。
