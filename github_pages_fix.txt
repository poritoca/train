GitHub Pages 向けメモ v21

更新方法
--------
配布ZIPを展開し、中身をGitHub Pagesの公開ディレクトリへ同名上書きしてください。ZIPそのものを置くだけではPagesは展開しません。

必須
----
index.html と sw.js は必ず同時に更新してください。

更新確認
--------
画面上部が「SILENT JOURNEY · 21」ならindex.htmlは最新版です。Service Workerキャッシュは21.0です。

オンライン解析キャッシュ
----------------------
parser6へ更新しているため、v20以前の誤解析キャッシュは自動破棄されます。
