GitHub Pages 向けメモ v42

更新方法
--------
配布ZIPを展開し、中身をGitHub Pagesの公開ディレクトリへ同名上書きしてください。ZIPそのものを置くだけではPagesは展開しません。

必須
----
`index.html` / `sw.js` / `guide-source-index.json` は必ず同時に更新してください。
画面上部が `SILENT JOURNEY · 42` になっていることを確認してください。
Service Workerは `42.0` です。古い表示が残る場合はSafariでページを再読み込みしてください。

v42の取得・解析方針
------------------
1. index.html内の検証済み駅別詳細URL + `guide-source-index.json` の詳細URLを優先
2. 同一駅に確認済み詳細ページが複数ある場合は全ページを取得して統合
3. 1文に複数路線・複数番線の到着案内がある場合、選択路線に一致する事実だけを抽出
4. 抽出後の方向が1方向へ一意に収束するときだけ、その方向文脈を後続の設備位置へ継承
5. 方向が割れる場合は推測せず fail-closed
6. 必要に応じて確定済み全駅簡易版で不足方向を補完
7. ここまでで取れない場合だけ WordPress REST の駅名検索
8. REST候補はタイトルの対象駅一致を必須化
