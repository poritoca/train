GitHub Pages 向けメモ v20

更新方法
--------
配布ZIPを展開し、中身をGitHub Pagesの公開ディレクトリへ同名上書きしてください。ZIPそのものを置くだけではPagesは展開しません。

必須
----
index.html と sw.js は必ず同時に更新してください。ZIP内のレポート類も固定ファイル名なので、そのまま上書きできます。

更新確認
--------
画面上部が「SILENT JOURNEY · 20」ならindex.htmlは最新版です。Service Workerキャッシュは20.0です。

オンライン案内
--------------
GitHub Pagesから掲載元を直接取得できないケースに備え、Jina Reader と AllOrigins の二経路を利用します。v20ではさらに、路線別ページで駅が見つからない場合に総合停車位置一覧から駅別詳細ページを探索します。

キャッシュ
--------
オンライン号車案内の解析キャッシュは parser5 です。旧parser4以前のキャッシュは起動時に削除されるため、三ツ沢上町などの旧失敗/誤解析結果を引き継ぎません。
