駅間ナビ v18
============

概要
----
GPSで現在位置・前駅・次駅・目的駅を表示する乗車ナビに、独立した「降車位置ガイド」を追加した版です。v15のGPS対応43路線・ガイド専用13路線・GUIDE_DATA 189レコードをそのまま保持しています。

降車位置ガイドの2つの使い方
--------------------------
1. 乗車中の降車駅
   乗車画面で設定した目的駅・選択路線・推定方向を使って表示します。
2. 駅から探す
   GPS不要です。路線 → 駅 → 方面を選ぶだけで同じ降車位置案内を確認できます。

対応規模
--------
全ガイド対象: 56路線 / 1359駅×路線 / 902ユニーク駅
アプリ内表示: 1211駅×路線 / 813ユニーク駅
静的内蔵: GUIDE_DATA 189レコード / 71駅×路線

v15までに追加済みのガイド専用路線
---------------------------
都営浅草線、都営三田線、都営新宿線、都営大江戸線、西武新宿線、西武拝島線、京王井の頭線、りんかい線、東急大井町線、つくばエクスプレス、東京モノレール、東武スカイツリーライン等、京成本線。
これらは降車位置ガイド専用で、GPS路線判定には使用しません。

データ精度
----------
静的詳細データは号車・ドア位置を表示します。全駅簡易版は号車単位、駅別詳細ハブは掲載元の詳細ページを取得して表示します。掲載元にないドア番号を推測して生成しません。

通信・キャッシュ
----------------
オンライン案内は初回通信が必要です。取得に成功した駅の結果は端末に90日キャッシュします。掲載元の構造変更などで自動取得できない場合は掲載元リンクを表示します。

一覧ファイル
------------
station_support.json: 全駅・全駅×路線の true/false と対応方式
all_station_support.txt: 全駅の supported / inApp 一覧
supported_stations.txt / unsupported_stations.txt / partially_supported_stations.txt
station_coverage_report.tsv: 全駅×路線の明細
source_inventory.tsv: 対応ソース一覧（v15内容を継承）
validation_report.txt: 検証結果

[v16 追加修正]
簡易版ページの「5号車（1号車）：階段」のような表記について、括弧内の号車を設備名として誤表示しないよう解析を修正しました。括弧内が10両編成時や別ホーム時の号車である場合は、「10両編成時：1号車付近」のように別条件として表示します。旧オンライン解析キャッシュは自動的に無効化されます。

[固定ファイル名運用]
GitHub Pages への更新時に同名ファイルとして上書きできるよう、v16以降の配布ZIP内ではレポート・一覧ファイル名に版番号を付けません。
例: station_support.json / station_coverage_report.txt / validation_report.txt
外側のZIP名だけは履歴管理のためバージョン・連番を残します。
GitHub上に残っている *_15.* / *_16.* など旧版レポートは、参照されなくなったため一度だけ削除して構いません。


[v17 初回オンライン取得の安定化]
- 新小岩・錦糸町などで「初回だけ自動取得に失敗し、再取得するとすぐ表示される」現象を修正。
- 掲載元のページ分割を駅数から推測するだけでなく、1ページ目の「その他各駅」リンクを読み取り、対象駅を含むページを特定します。
- 例: 横須賀・総武快速線は新小岩〜東京が3ページ目で、登録駅数からの旧推定では外れることがありました。
- 初回の外部取得がコールド状態で失敗した場合、700ms後に自動で第2波を実行します。手動の「再取得」を押す前にアプリ自身が再試行します。
- 対象候補は3ページずつ並列確認し、誤った候補を1ページずつ待つ長時間待ちを減らしました。
- 取得済みページは同一セッション内で共有し、同じページの重複取得を抑えます。
- 対応駅数、GPS路線、GUIDE_DATA 189レコード、固定ファイル名運用は変更していません。


[v18 方面判定・駅名表記揺れ・初回取得の徹底修正]
- 方面判定を、単純な文字列一致から路線別スコア方式へ変更しました。
- 上り/下り、東西南北、外回り/内回り、終点、主要方面駅、路線内の駅順、掲載元ラベルを組み合わせて判定します。
- 中央・総武各停と総武快速など、同一駅ページ内に複数系統が載る場合は対象路線だけを抽出します。
- 掲載元が方面共通の簡易版なら「両方向共通の案内」として表示し、不一致扱いしません。
- 本当に判定できない時だけ、方面ごとに独立した枠へ分けて表示します。
- 保土ケ谷/保土ヶ谷、市ケ谷/市ヶ谷、茅ケ崎/茅ヶ崎、四ツ谷/四谷等の表記揺れを吸収します。
- 上野/上野広小路、新宿/新宿三丁目等の前方一致を避ける駅名境界判定を追加しました。
- 全駅ページ→駅別詳細ページ→既知詳細URLの探索を補強し、最大16候補まで確認します。
- Jina Reader / AllOrigins の二重取得と自動再試行を維持し、全体探索失敗時は900ms後に再探索します。
- 動的キャッシュは ekikan-guide-dynamic-v18-parser4。旧解析結果は自動破棄します。
- Service Workerは18.1です。
- 個別方面判定30/30、全登録路線方向マトリクス406/406をPASSしています。
- 対応駅数・路線・GUIDE_DATA 189レコードはv17から変更していません。
