駅間ナビ v20
============

概要
----
GPS乗車ナビと独立した「駅から探す」降車位置ガイドを備えた版です。v19の乗車パンくずUI・GPS自動復帰・方面判定・静的GUIDE_DATA 189レコードを保持したまま、未対応駅とオンライン取得失敗要因を追加改善しました。

対応規模
--------
全ガイド対象: 56路線 / 1359駅×路線 / 902ユニーク駅
アプリ内表示: 1258駅×路線 / 853ユニーク駅
完全未対応: 101駅×路線 / 49ユニーク駅
静的内蔵: GUIDE_DATA 189レコード / 71駅×路線

v20の主な追加
-------------
1. 小田急小田原線47駅を対応済みに格上げ
   公開元の総合停車位置一覧から対象駅の駅別詳細ページを解決し、アプリ内で号車/設備位置を取得します。
2. 三ツ沢上町の取得失敗を修正
   アプリの「三ツ沢上町」と掲載元の「三ッ沢上町」を同一駅として扱います。三ツ沢下町も同様です。
3. 簡易版のコロン無し書式を解析
   「6号車（エレベーター・階段・エスカレーター）」形式を読み取ります。
4. 詳細ページ解析を強化
   最近の掲載元レイアウトで「停車位置」という共通見出しがなくても、駅名確認後の方面・番線・設備見出しから解析を開始します。
5. ページ特定の最終フォールバック
   路線別一覧・候補ページ・既知詳細URLで見つからない場合、総合停車位置一覧から駅別詳細URLを検索します。
6. 旧誤解析キャッシュを破棄
   オンライン解析キャッシュを parser5 へ更新しています。

降車位置ガイドの使い方
----------------------
- 「乗車中の降車駅」: 乗車ナビの路線・方向・目的駅を利用。
- 「駅から探す」: GPS不要。路線 → 駅 → 方面を選んで参照。

通信・精度
----------
オンライン案内は初回通信が必要です。取得成功後は90日キャッシュします。公開元にないドア番号を推測して生成しません。取得できない駅は false のまま残し、掲載元リンクを表示します。

固定ファイル名
--------------
GitHub Pagesで毎回同名上書きできるよう、ZIP内部の一覧・レポート類は固定名です。外側のZIP名だけバージョンと連番を持ちます。

一覧ファイル
------------
station_support.json: 全駅・全駅×路線の true/false と対応方式
all_station_support.txt: 全駅の supported / inApp 一覧
supported_stations.txt / unsupported_stations.txt / partially_supported_stations.txt
station_coverage_report.tsv: 全駅×路線の明細
source_inventory.tsv: 対応ソース一覧
changes.txt: 今回の変更
validation_report.txt: 検証結果
parser_regression_tests.txt: オンライン解析の回帰テスト
