【オンライン簡易号車案内の動作】
1. 降車駅を選択します。
2. 静的GUIDE_DATAがある駅は従来どおりオフラインで表示します。
3. 静的データがなく、確認済み全駅簡易版の対象駅なら、公開ページをJina Reader経由で読み込みます。
4. 駅見出しの範囲だけを抽出し、「号車」「前方/中方/後方」「階段・エレベーター等」の記載をアプリ内に表示します。
5. 成功結果は駅ごとに90日間 localStorage へ保存し、同じ駅で再利用します。
6. 自動取得に失敗しても、従来の掲載元リンクは残ります。

【精度・安全策】
・オンライン簡易版でドア番号は生成しません。掲載元の簡易版にドア番号がないためです。
・号車は公開ページ本文に実際に記載されたものだけを抽出します。
・駅見出しが見つからない、号車記載が抽出できない場合は「取得失敗」とし、推測値を表示しません。
・同一ページ内で方面/番線見出しがある場合は、その見出しをそのまま表示します。
・設備工事、休止、ホーム運用は変更されるため、現地案内を優先してください。

【通信について】
静的GUIDE_DATAは完全オフラインです。オンライン簡易号車案内の初回取得では通信が必要です。
公開ページのテキスト取得には Jina Reader API (https://r.jina.ai/) を使用します。APIキーは不要ですが、匿名利用にはレート制限があります。
