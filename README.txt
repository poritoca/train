駅間ナビ v43
============

概要
----
v42を基準に、駅名から最短操作で降車位置ガイドへ進める「駅名クイック検索」を追加した版です。v42までのオンライン号車案内解析、元住吉修正、エレベーター号車強調、GPS乗車ナビは維持しています。

v43の駅名クイック検索
----------------------
- 4つのメインタブ（乗車／降車位置／設定／履歴）の直上に、常時使える「駅名で降車位置を検索」欄を追加。
- `type=search` + `enterkeyhint=search` のフォームとして実装し、iPhone Safariのキーボードに表示される「検索／確定」操作から検索を実行できます。画面上の「検索」ボタンでも同じ処理を実行します。
- 入力中も短い待ち時間で候補を更新するため、Enterを押さず候補を選ぶこともできます。
- 駅名を検索すると、「駅名｜路線名」の組み合わせをプルダウン表示します。例: `日吉｜東急 目黒線`。同名の路線ラベルが複数ある場合だけ区間名も付けて区別します。
- 完全一致する駅名が1つ以上ある場合は、`新宿` 検索で `新宿三丁目` や `西武新宿` を混ぜず、完全一致駅の路線だけを先に表示します。
- 完全一致がない場合は前方一致、部分一致の順で候補を表示します。
- 表記ゆれは既存の駅名正規化を利用します。例: `浜松町` で `モノレール浜松町` も同一駅名系として候補化できます。
- 候補が1件だけの場合は、その駅・路線を自動選択して「方面」の選択まで1ステップ短縮します。
- 駅・路線を選ぶと方面プルダウンだけを表示し、方面を選んだ瞬間に「降車位置」タブへ移動して該当駅・路線・方面のガイドを描画します。
- クイック検索の候補パネルはタブ上に重なるオーバーレイ式にしており、通常時の画面高さを検索欄1行分以上圧迫しません。
- 検索候補は降車位置ガイドが扱う `ALL_GUIDE_ROUTES` から生成するため、個別駅リストを二重管理しません。

操作手順
--------
1. 画面上部の検索欄に駅名を入力して、iPhone Safariの「検索／確定」または画面の「検索」を押す。
2. 「駅名｜路線名」を1つ選ぶ。候補が1件ならこの操作は不要。
3. 方面を選ぶ。
4. 自動で「降車位置」タブへ移動し、号車・設備案内を表示。

v42から維持している内容
-----------------------
- 元住吉など複数路線・複数番線が同一文章に併記される掲載元の安全な解析。
- 反対方向や別路線の曖昧データを誤表示しない fail-closed 方針。
- エレベーターに近い号車カードの共通強調（EV表示、枠線・背景強調）。
- GPS乗車ナビ、履歴、降車通知、駅から探す従来画面、オンライン案内キャッシュ。

互換性・キャッシュ
------------------
- 動的案内パーサーはv42と同一のため、オンライン案内キャッシュは `ekikan-guide-dynamic-v42-parser28:` を継続利用します。
- 意味解析パーサー: `dom-semantic-1.18.0`
- Service Worker: `43.0`
