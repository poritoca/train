駅間ナビ v46
============

最後に配布したv45（202609220707_ekikan_gps_45_36.zip）からの更新です。
検索を降車位置タブへ移動し、ホームの文言と重複ボタンを整理しました。
時刻表機能は見送り、追加していません。

降車位置を駅名で調べる
----------------------
「降車位置」タブの一番上に、駅名入力欄と検索ボタンを配置しました。
駅名を入力すると路線付きの候補が出るので、方面を選びます。
日本語IME・検索履歴・完全一致優先は維持しています。別駅を調べても見守り先は変わりません。
従来の路線／駅／方面のプルダウンは「路線・駅・方面を一覧から選ぶ」にまとめました。
案内の下までスクロールしていても「降車位置」タブを押すと検索欄へ戻れます。

iPhoneの通知・振動
------------------
「その他 → iPhoneの通知・振動の設定」で、方法の説明と設定補助を開けます。
見守り中の「その他の操作」、プリセット管理の「通知の設定」からも使えます。
ブラウザ別の対応と詳しい手順・出典は、同梱の iphone-alerts.html を参照してください。

A. 画面を開いて使う場合
無料のBrrrowserは、開発元がHTMLのバイブAPI対応を案内しています。
アプリ内の「このページのURLをコピー」で公開URLをコピーし、Brrrowserで開いて試せます。
バイブAPIを検出した環境では「バイブを試す」「10秒後に試す」を表示します。
10秒後のテストは、この案内・ページを閉じるか非表示になると中止します。手動でも中止できます。
APIの実行要求と実際の振動は別なので、実機で触覚を確認してください。
本アプリとのGPS・画面保持・振動の組み合わせは未検証です。位置取得も確認してから使用してください。
別ブラウザへプリセットは自動移行しません。「ファイルに書き出し／読み込み」を使います。

B. 画面を閉じて使う場合
標準の「ショートカット」で、各駅への到着オートメーションを設定する方法を案内しています。
現在の区間以降の降車駅・乗換駅、または選んだプリセットの全降車駅をコピーできます。
「到着」→「デバイスを振動させる」→必要なら「通知を表示」を手動で設定します。
ストア公開や開発者登録は不要です。地下・位置誤差・通知の遅れがあるため、実際の移動で試してください。
ショートカット側の設定は別管理です。このアプリの変更・全解除・削除とは連動しません。
駅名コピーや「ショートカットを開く」だけで通知設定が完了するわけではありません。

Safari・Chrome・Edge・Firefoxの通常のiPhone版では、標準の自動バイブAPIは非対応です。
ホーム画面のWebアプリはWeb Pushに対応しますが、ロック中のGPS監視を可能にするものではありません。
今回Web Pushのサーバーや配信機能は追加していません。ブラウザ内では画面表示中の見守りが基本です。

駅名検索で経路を設定する
----------------------
1. ホームの「往路」または「復路」を選び、「経路を設定する」（保存済み経路がある場合は「新しい経路」）を押します。
2. 「乗る駅」「降りる駅」に駅名を入力します。候補に駅名と路線が一緒に表示されます。
3. 候補を押すと駅と路線を反映します。現在の路線の候補を優先します。
4. 「乗換を追加」で次の区間を設定します。最大8区間です。
5. 「この端末に保存」で、乗換を含む経路全体をプリセットとして保存します。
6. 保存せずその日だけ使う場合は「今回だけ開始」を押します。

検索は新規設定・保存済みプリセットの編集・見守り中の「今回の経路を変更」のすべてで使えます。
完全一致駅があればその駅を優先し、日本語の変換途中には候補を更新しません。
候補の路線へ変更した際、もう一方の駅がその路線にない場合は空欄に戻して選び直せます。
駅名を編集しただけでは見守り先は変わりません。変更画面の「今回の経路に適用」を押した時点で反映します。

往路／復路のプリセット
----------------------
- ホームと「保存した経路」の管理画面に往路／復路のタブがあります。
- 編集画面上部の「往路に保存／復路に保存」で保存先を選べます。既存のプリセットも移動できます。
- 管理画面の「復路を作成」は、区間順・乗車駅・降車駅・方面を逆にした下書きを作ります。保存するまでは元の経路を変更しません。
- プリセットは往路・復路合わせて最大30件です。
- v44で保存した分類のないプリセットは、内容を保ったまま往路に表示します。編集画面で復路へ変更できます。
- 見守り中の変更画面では「別のプリセットとして端末に保存」も使えます。元の保存内容や実行中の経路を勝手に上書きしません。

端末内への保存とファイルへの書き出し
----------------------------------
「この端末に保存」は、このブラウザのlocalStorageへ保存します。
同じ端末・ブラウザで開き直すと残りますが、ブラウザのデータを消した場合や別のブラウザでは引き継がれません。
「保存した経路」下部の「ファイルに書き出し」から、往路・復路を含むJSONファイルを保存できます。「読み込み」で復元できます。
従来の分類なしJSONも読み込めます。端末内に保存できなかった場合は失敗を表示し、入力内容を画面に残します。

全解除と削除
------------
- 見守り主画面の「今回の設定を全解除」: 継続測位・降車通知を止め、今回の全区間と再開候補を解除します。保存済みプリセットは残します。
- 初回設定／プリセット編集の「入力した設定を全解除」: 入力中の区間を空欄の1区間へ戻します。保存済みの元のプリセットは残します。
- 見守り中の変更画面の「今回の設定を全解除」: 見守りも終了し、新しい空欄の設定画面に戻します。
- 管理画面の「削除」、編集画面の「このプリセットを削除」: 選んだ保存データだけを削除します。すでに見守り中の経路はそのまま動作します。

次の停車駅までの10区切り表示
----------------------------
v44では従来の表示が詳細欄内にあり、見守り中に隠れていました。
v45から見守り主画面の「次の停車駅」の下に、駅名・10分割のバー・現在位置の印・割合を表示します。
前の停車駅から次の停車駅までを10分割し、選択した停車パターンに従って計算します。通過する駅でバーを区切り直しません。
逆方向・環状線の折返し位置にも対応します。GPSが古い場合は「推定位置」、手動補正時は「手動の現在駅」と表示し、位置未取得時には割合を出しません。
乗換準備中・目的駅への到着確認後は、その区間の進捗バーを隠します。

引き継いだ機能
--------------
- 見守り開始前の経路候補、複数区間の乗換、途中区間からの開始、今回だけの変更。
- 降車位置タブ内の駅名検索、別駅を検索中の見守り継続、EVに近い号車の強調。
- 遠い区間だけの自動省電力、位置が古くなった際の通常復帰、中断後の再開候補、見守り中の更新保留。
- 路線データ・駅の対応範囲・掲載元インデックス・降車位置の解析処理。
