駅間ナビ v21
============

概要
----
GPS乗車ナビと独立した「駅から探す」降車位置ガイドを備えた版です。v20の対応駅・乗車UI・GPS自動復帰・静的GUIDE_DATA 189レコードを保持したまま、オンライン詳細ページ内の方面表記矛盾に強い解析へ更新しました。

対応規模
--------
全ガイド対象: 56路線 / 1359駅×路線 / 902ユニーク駅
アプリ内表示: 1258駅×路線 / 853ユニーク駅
完全未対応: 101駅×路線 / 49ユニーク駅
静的内蔵: GUIDE_DATA 189レコード / 71駅×路線

v21の主な修正
-------------
1. 掲載元内部の上り/下り誤記に耐える方向補正
   方面駅・路線順・終点/主要方面語から方向を再判定し、明確に矛盾する上り/下り表記だけを補正します。
2. 両方向の号車をまとめた設備見出しを誤データ化しない
   例: 「エスカレーター（横浜方面: 7号車…、渋谷方面: 6号車…）」は設備種別の見出しとして保持し、実際の「下り: 横浜方面」「上り: 渋谷方面」節で号車を取得します。
3. 方面見出しを短く整理
   番線・上り下り・主要方面を「2番線ホーム · 上り: 渋谷・池袋方面」のように表示します。
4. 旧解析キャッシュを破棄
   オンライン解析キャッシュを parser6 へ更新しました。

反町の例
--------
掲載元の詳細ページには、冒頭では「2番線=上り: 渋谷方面」とある一方、詳細節の一部に「2番線=渋谷・池袋方面(下り)」という矛盾があります。v21では方面駅と路線方向を優先して「上り」として扱い、方向別の実データ節から号車を取得します。

降車位置ガイドの使い方
----------------------
- 「乗車中の降車駅」: 乗車ナビの路線・方向・目的駅を利用。
- 「駅から探す」: GPS不要。路線 → 駅 → 方面を選んで参照。

通信・精度
----------
オンライン案内は初回通信が必要です。取得成功後は90日キャッシュします。公開元にないドア番号を推測して生成しません。取得できない駅は false のまま残し、掲載元リンクを表示します。

固定ファイル名
--------------
GitHub Pagesで毎回同名上書きできるよう、ZIP内部の一覧・レポート類は固定名です。外側のZIP名だけバージョンと連番を持ちます。
