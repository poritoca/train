HTTPやローカルファイルではGPS・オフライン機能が使えない場合があります。
GitHub PagesのHTTPSのURLで開いてください。

【使い方】
1. 乗っている路線・直通系統を選ぶ。
2. 「GPSで現在地を確認」を押す。
3. 「あなたが降りる駅」を選んで「降車駅の見守りを開始」。
4. 急行・快速は「乗車の設定」→「列車の行先・停車駅」で通過駅を外す。
5. 混雑中は「集中表示」にすると現在駅・次駅・降車案内を大きく表示。

【今回の追加】
・黒基調のすりガラス調カード、細い虹色アクセント。
・停車してから開いても方向判定を待たず現在駅の候補を表示。
・GPSから駅付近の停止を確認すると、大きな文字で駅名を表示。
・自分の降車駅と列車の終着駅を別に設定。
・残り駅数、距離、途中停車を含めた到着の目安、進捗バー。
・1駅前、設定距離以内、到着の目安が設定時間以内、到着、通過した可能性を表示。
・GPS途絶時は最後の到着予測に基づく「時間のお知らせ」。到着は確定しない。
・「時間でも確認する」は、見守り開始から任意の時間でお知らせ。
・対応端末で短いバイブ。未確認なら20秒おき、1段階につき最大3回。
・「確認しました」で繰り返し停止。到着・通過のお知らせ確認後は見守り終了。
・前回の降車駅を路線別に保存。再読込時は勝手に監視を開始しない。
・画面復帰時にGPSを取り直す。古いGPSや長い受信空白を到着の証拠にしない。
・Safari「共有」→「ホーム画面に追加」で専用画面として起動可能。
・初回に通信がある状態で開いた後は、オフライン起動に対応。

【iPhoneについて：大切な制約】
iPhone Safariは navigator.vibrate に対応していないため、自動バイブは使えません。
対応状況を画面で検出し、非対応の場合は明示します。
バイブがある端末でも「バイブを試す」で実際に振動するか確認してください。

Webページは非表示・画面ロック時に位置情報取得やタイマーが止まります。
このHTMLだけで、iPhoneをロックしたまま自動で起こすことはできません。
ホーム画面に追加しても、継続的なバックグラウンドGPSは有効になりません。
表示中の画面スリープ防止を備えていますが、省電力設定等で解除されることがあります。
「画面保持 ON」を確認してください。
画面を閉じている間に確認時刻を過ぎた場合は、戻った時点でお知らせします。
寝ている間の確実な通知が必要な場合は、端末側のアラーム等も別途設定してください。
音を出さない設定は端末側で確認してください。

既存の音声案内は削除しました。アプリには音・音声の再生処理がありません。
OS通知・プッシュ通知は使いません。通知音が意図せず鳴る方式は導入していません。

【精度と収録範囲】
03版の路線・座標データをそのまま引き継いでいます。
収録区間は路線選択肢に表示しています。区間外の直通先は自動切替しません。
駅の概略座標を結ぶ方式のため、ホームや線路のカーブは再現していません。
駅近くの停止がホームへの到着とは限りません。車内案内も確認してください。
到着の目安は速度・途中停車からの概算です。時刻表・運行情報は取得しません。
低精度時・未測位・GPS途絶時の表示を、実測での到着とは区別します。
地下では最初からGPSを取得できず、位置の予測を開始できない場合があります。

【保存と更新】
設定・履歴は同じ端末・同じブラウザ内に保存。位置情報の外部送信はしません。
路線または進行方向を変更した時は、降車駅の見守りを開始し直してください。
更新後に旧画面が出た場合は、通信可能な状態で再読み込みしてください。
サイトデータを削除すると、履歴・設定・オフライン用データも消えます。

【検証】

iPhone Safari実機・実走行・実際の振動・実画面の描画は未検証です。
