【v10 の主な追加】
・横浜駅：既存のJR東海道線・横須賀線・湘南新宿ライン・京浜東北線・ブルーラインに加え、
  JR横浜線、東急東横線・みなとみらい線、相鉄線、京急線の降車位置案内を追加しました。
・編成差：東横系8/10両、相鉄8/10両、京急4/6/8/12両を編成フィルターで切り替えられます。
  GPSだけでは編成長を判定しないため、編成不明時は候補をすべて表示します。
・東京メトロ銀座線：17駅にアプリ内の案内を用意しました。既存の新橋・虎ノ門の詳細ドア案内は維持しています。
・東京メトロ日比谷線：北千住・南千住・三ノ輪・入谷・上野に簡易号車案内を追加しました。
・都内主要路線：山手線、中央線快速、中央・総武線、埼京線、京葉線、常磐線快速、南武線、武蔵野線、
  宇都宮線、高崎線、東京メトロ主要線、京王線、西武池袋線などに、路線全体の公開案内への導線を追加しました。

【詳細版と簡易版】
・詳細版：号車＋ドア番号まで表示します。v09までの詳細データは削除・巻き戻しせず維持しています。
・簡易版：号車単位で表示します。掲載元でドア番号まで確認できる場合でも、今回の追加分は誤転記防止を優先し、
  アプリ側でドア番号を推測・補完していません。
・簡易版の車両図は「号車番号の小さい順」に表示し、先頭車の向きと混同しないよう画面に明記しています。

【横浜駅の編成差】
・東急東横線・みなとみらい線：8両 / 10両
・相鉄線：8両 / 10両
・京急線：4両 / 6両 / 8両 / 12両
到着ホーム・編成が不明な場合は候補をまとめて表示します。車内表示やホーム案内で確認できた場合は、画面の絞り込みを使ってください。

【既存機能】
GPSで駅間の現在位置と次駅を表示、GPS途絶時の想定進行と復帰補正、路線候補・方向判定、
降車駅の路線方向別保存、到着前の無音バイブ、画面スリープ防止、デモ移動、更新間隔選択を維持しています。

【出典と注意】
降車位置は、公開の駅別・路線別案内を2026-09-18時点で確認して収録しています。
詳細は station_coverage_report_10.txt を参照してください。
駅設備、工事、ホーム運用、編成は変更されることがあります。現地の案内を優先してください。
