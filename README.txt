駅間ナビ v42
============

概要
----
v41を基準に、追加報告された元住吉（東急目黒線）のオンライン号車案内失敗を解析し、東横線・目黒線のような「同じ文章内に複数路線・複数番線が併記され、その直後に設備位置が続く」ページを安全に扱う共通処理へ修正した版です。
あわせて、号車カードではエレベーターに近い号車だけを少し強く見分けられるよう、全駅共通の表示ルールを追加しました。

v42の重要な変更
----------------
- 元住吉×東急目黒線: 確認済み詳細ページ `motosumiyoshi-tokyumeguro-toyokohome-info` を直接優先します。
- 元住吉: 1文の中に「2番線=東横線下り / 3番線=目黒線下り」など複数の到着情報がある場合、従来のように文全体を曖昧として捨てず、選択路線に一致する事実だけを抽出します。
- 同じ選択路線について複数番線が残っても、それらが同じ方向に確定する場合だけ設備ブロックへ方向文脈を引き継ぎます。
- 選択路線内で正反対の方向が同時に残る場合は、従来どおり方向文脈を採用せず fail-closed にします。
- 元住吉の回帰テストでは、目黒線3番線=日吉方面(+1)、4番線=目黒方面(-1)を保持し、東横線2・5番線を目黒線の案内へ混入させないことを確認しています。

エレベーター号車カードの共通強調
------------------------------
- 動的オンライン案内: 実際の解析結果 `detail` に「エレベーター」が含まれる号車だけ、通常の選択カードより枠線と背景を少し強調します。
- 収録済み静的案内: 設備種別 `types` に `elevator` がある号車だけ同じ強調を適用します。
- 「階段・エレベーター」の複合設備もエレベーターありとして強調します。
- 階段だけ、エスカレーターだけの号車は従来表示のままです。
- 駅名リストによる個別指定ではなく、各駅の実データに基づくため、現在および今後エレベーター情報を取得できる全駅へ自動適用されます。
- 強調号車には小さく `EV` を表示し、aria-labelにもエレベーター情報を付与します。

安全側の条件
--------------
- 複数候補をまとめるのは、選択路線に一致し、かつ最終的な方向が1方向へ一意に収束する場合だけです。
- 選択路線内で方向が割れる場合、設備ブロックへ方向を継承しません。
- 別路線の番線は、路線文脈が確認できる場合に除外します。
- v41までの対象駅タイトル一致、既知詳細URL優先、取得上限、反対方向の誤表示防止などの安全策は維持しています。

掲載元インデックス拡張
----------------------
- 東急目黒線: 元住吉の確認済み駅別詳細URLを追加。
- v41までの日吉、新宿、大井町などの確認済みURLは維持。

互換性・キャッシュ
------------------
- v41までのGPS乗車ナビ、静的駅データ、履歴、UI、fail-closed方針は維持。
- 動的案内キャッシュ: `ekikan-guide-dynamic-v42-parser28:`
