v46 動作・回帰確認
=================
本番HTML/JavaScriptをjsdom 26.1.0で実行し、測位・時刻・ダイアログ・外部取得・バイブAPIを模擬して確認しました。
実機の描画・GPS・物理振動の試験ではありません。テスト用の内部状態公開は配布コードに含みません。

v46の変更（15項目）
------------
1. PASS: Guide search is first inside its tab; other tabs hide it and opening Guide returns to the search
2. PASS: Visible first-route action replaces the duplicate and saved-route actions return after save
3. PASS: Guide search handles IME, visible results, selection and aria state without changing a live journey
4. PASS: Clear, empty results, escape and revisiting the guide keep the correct search state
5. PASS: An unsupported browser shows the explanation and setup help without starting GPS or a permission request
6. PASS: Native vibration remains opt-in to the existing test action and is not triggered by opening help
7. PASS: Preset setup lists every transfer destination, copies only the chosen station and leaves local data unchanged
8. PASS: Current journey setup shows remaining legs and never mutates or stops the active trip
9. PASS: Clipboard rejection offers selectable station text without reporting notification setup success
10. PASS: A late clipboard failure does not reopen or overwrite another dialog
11. PASS: Return-folder setup escapes preset labels and does not select an outbound route
12. PASS: Clearing the current trip removes its helper destinations while both saved folders remain available
13. PASS: Browser migration copies the app URL without query parameters or fragment
14. PASS: Delayed vibration is explicitly scheduled, can be cancelled, and fires only once while visible
15. PASS: Closing the guide or hiding the page cancels pending vibration tests
